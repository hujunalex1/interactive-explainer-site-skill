# SVG 互动实验室规范、实战避坑录与 QA 清单

## 1. 第一性原理的视觉翻译原则

写每一个 SVG 实验室之前，先问自己三个问题：**“如果把图上的文字全删掉，读者还能一眼看出发生了什么吗？”**

| 抽象概念 | 错误画法（晦涩） | 正确画法（第一性原理直觉） |
| :--- | :--- | :--- |
| **气体压缩 / 冷却增密** | 只改一个数字“进气密度 1.4” | 直接画出稀疏高温红点经过冷却器变成密集低温青点 |
| **能量流 / 信号流** | 画一条静态实线 | 叠加流动虚线（`strokeDashoffset`）或方向粒子 + 粗细/速度随功率变化 |
| **受力与传递** | 只在角落写扭矩值 | 直接在作用点画动态缩放的粗箭头、轮载圆圈或机身俯仰角 |
| **摩擦生热 / 能量耗散** | 写文字“半联动发热” | 摩擦面发亮泛红 + 浮动热浪线条，温度越高发光越强 |
| **方案对比（有无某机制）** | 切换开关后旧状态消失，靠脑子记 | 保留**虚线幽灵曲线（Ghost Curve）**，把关闭/开启前后的峰值直接叠在同一坐标系对比 |
| **几何约束 / 干涉** | 只给公式说明 | 真实画出轮轴垂线/包络轨迹，让用户亲眼看见“同心圆平滑转弯” vs “双圆打架拖胎” |

### 6 种高复用实验原型（Break-It-To-Learn）
设计每课 Lab 时，至少覆盖以下一种可“推向极端”的交互模式：
1. **运动学分步剖析**：提供“连续播放 / 手动单步（逐度/逐相）”切换，附带实时相位图或 P-V 曲线。
2. **闭环能量/流体链路**：标出 ①→②→③→④ 序号节点，并配一个开关控制关键部件（如中冷器、旁通阀），开关一拨粒子密度/流向立变。
3. **极端失效与救场开关**：先允许人为制造恶劣条件（冰雪打滑、无 ABS 抱死、零阻尼共振），再点开关启用补偿机构（差速锁、ABS 脉冲、阻尼器），对比前后动画与曲线。
4. **结构形变对比**：把刚体固定端与碰撞墙精准贴合，对比“刚性硬扛（瞬间尖峰 G 值）”与“折痕手风琴式溃缩吸能（延长缓冲时间、削平峰值）”。
5. **信号抗噪与差分还原**：实时注入抖动的共模噪声到两条信号线，下方示波器同步展示 `V+ − V-` 如何把噪声完全抵消，恢复干净方波。
6. **拓扑切换与载荷转移**：切换架构（如 FF/FR/MR/AWD 或串/并联）并拖动加减速/坡度滑块，同步联动重心转移箭头、部件高亮与整机姿态俯仰。

## 2. SVG 几何与工程实战避坑录（血泪清单）

以下全是从真实构建与浏览器截图 QA 中踩出并修复的坑，**编码阶段直接规避**：

### A. 样式与主题安全
1. **SVG 严禁硬编码 `#000` / `#fff`**：文字、主轮廓、卡片填充必须用 `var(--foreground)`、`var(--card)`、`var(--sunken)`、`var(--border)`、`var(--muted-foreground)` 及 `var(--cat-*)`；高对比胶囊徽章（如数据帧、状态标签）在深浅模式下都要检查背景与文字反差。
2. **反引号检查**：SVG `transform` 动态拼接（例如 ``transform={`translate(${x}, ${y}) rotate(${angle})`}``）切勿写成普通双引号 `"translate(...) rotate(${angle})"`，否则图形静止且无编译报错。

### B. 防重叠与防裁剪安全区
3. **顶部/曲线表头预留双行空间**：在示波器、P-V 图、G-t 图内部放标题与图例时，若水平宽度紧凑，拆为两行（主标题 + 副图例）并调低曲线最高点 `yMin`，严禁文字压在波形峰值或坐标系顶边上。
4. **边缘标签留足 Padding**：靠近 `viewBox` 左右边界的标注（如右轮说明、右侧终端电阻、坐标轴刻度）必须留出至少 `14–20px` 安全边距，并用合适的 `textAnchor="start" | "middle" | "end"`，防止字母或汉字被 SVG 边界硬切。
5. **动态缩放元素的极值边距**：随滑块放大缩小的圆圈（如车轮垂向载荷圆）、伸缩箭头或跳动车身，必须按**最大可能值**预留 `viewBox` 上下左右留白，避免推到最大滑块时顶破边界或压住下方说明文字。
6. **射线几何裁剪用 `<clipPath>` 而不是坐标钳位**：画延长线（如转向轮垂线、光线折射延长线）时，绝对不要把终点 `x/y` 强行 `clamp` 到画布内，那会扭曲直线斜率导致交点错误；正确做法是按真实三角函数算出远端点，外层套 `<clipPath>` 裁剪到舞台矩形内。
7. **进度条/状态条文字外置**：电量条、温度条、制动距离条若数值可能很小时，不要把文字硬塞进彩色条内部，放在条上方/下方居中，防止低值时文字溢出条块。
8. **关键动画接触点坐标精确对齐**：碰撞墙与保险杠、啮合齿轮的节圆中心距（`R1 + R2`）、活塞顶面与缸盖止点、轮胎底面与动态滚动路面，必须用共享数学常量计算，禁止肉眼凑像素导致穿模或悬空。

### C. 运行环境
9. **依赖安装**：在无网络沙箱环境中 `npm install` 会挂起，如需联网装包仅对单条安装命令申请网络权限，其余构建、校验与开发服保持在沙箱内运行。

## 3. 多视口浏览器 QA 验收清单

交付前必须通过本地开发服务器 + 真实浏览器截图检查以下 5 项，全部通过才算完成：

1. **构建零错误**：`npm run build`（`tsc -b && vite build`）退出码为 0；确认编译后的 CSS 包含 `@theme inline` 生成的语义工具类。
2. **桌面默认视图（`1440×900`，浅色模式）**：
   - 首页 Hero 迷你实验台立即可交互，无水平滚动条；
   - 侧边栏粘性固定，滚动长课程页时侧栏不随正文滚走；
   - 逐一检查所有课程的 16:9 导学播放状态 + 核心实验室（含极端滑块值与开关状态），确认 0 文字重叠、0 标签截断、0 图形穿模。
3. **桌面收起侧栏视图（`1080×800`）**：
   - 点击收起侧边栏后，顶部展开按钮栏处于正常文档流，不遮挡课程面包屑或标题；
   - `⌘K` 搜索面板能打开、输入过滤、键盘回车跳转。
4. **深色模式全检**：
   - 切换至 Dark 模式后，所有页面背景/边框/滑块/开关圆点清晰可见；
   - 抽检所有实验室 SVG，无暗底黑字或亮底白字。
5. **移动端窄屏视图（`390×844`）**：
   - 汉堡菜单抽屉正常开关；
   - 所有 `LabSlider` 标签与右侧读数不重叠、不撑破容器；
   - 工具页计算器与课程数据表无横向页面溢出；
   - 全程浏览器 `console.error` = 0，`pageerror` = 0。
